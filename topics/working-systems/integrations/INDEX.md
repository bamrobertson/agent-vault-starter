# Integrations

No connection is set up in this starter. Create one note per service or source only when needed.

For each connection, record: owner, account/workspace identity, allowed read scope, allowed write scope, token storage location (never the token), tested operations, scheduled-run access, failure mode and last verified date. A successful read does not establish permission to write. Test narrow reads and direct read-back of authorized changes.

Keep secret values, private message exports and personal identifiers out of this repository.
